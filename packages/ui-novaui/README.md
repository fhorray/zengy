# `ui-novaui` (`community.ui.novaui`)

Optional community UI DSL (`NovaUI`) frontend compiling into the same [`ui-core`](../ui-core/README.md) `UiTree` intermediate representation as `ui-markup`.

## Design

- Proves alternative declarative UI syntaxes can target `UiTree` without any special-casing in `src/core/` or `ui-core`.
